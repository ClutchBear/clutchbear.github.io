### Console2
![](https://camo.githubusercontent.com/70b677bc38ebb6660c85273aed2b33489183b22a/687474703a2f2f61727261792e626c75652f696d616765732f636f6e736f6c65322d38646134303039302e706e67)

Windows的命令终端CMD和Powershell有点简陋和不实用，console2这个软件就好多了。
能设置成自己喜欢的字体、主题颜色什么的。

- 官方下载地址 ： [点击](http://sourceforge.net/projects/console)
- 配置和介绍：[大神的博客](http://raytaylorlin.com/Tech/IDE/console2-better-windows-cmd/)
- 能输入汉字的主程序：[github地址](https://github.com/raytaylorlin/Console2-Chinese-Input-Capable)
- 主题颜色：[github地址](https://github.com/tstone/console2-monokai)

### ipython
![](http://ww2.sinaimg.cn/large/7293e3b7jw1eus4tqoe0ej20p00gb76z.jpg)

ipython能够逐行显示python代码的运行结果，能够更好的调试python代码，并且有tab自动补全功能。

- 安装主程序：

```    
       pip install ipython
```
     
- 安装配色：

```
       pip install pyreadline
```
